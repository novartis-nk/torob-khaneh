## Safar photographs

`public/images/safar/` contains provider photographs captured from public catalog pages on October 5, 2026 for local prototype review. They are not AI-generated or owned by this project. Each record in `data/safar-catalog.json` retains its original CDN URL (`sourceImage`), provider listing URL, source page and observation time. Cards attribute the image to its provider. The postcard uses Otaghak listing 2512254's photograph; it is decorative destination context, not a claim about all Ramsar properties.

No redistribution license or provider partnership has been obtained. A public release should resolve source access and image usage arrangements. This prototype has not been published. Provider images are unedited; missing images display a neutral fallback rather than an unrelated photo.
